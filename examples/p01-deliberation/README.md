# p01: 两院制议事机制

验证公司两院制议事体系的可执行性。

## 权力来源

创始人是大股东和实际控制人，两院的权力由创始人让渡。

创始人特权包含但不限于一票否决权。不同特权根据性质选择不同行使路径：

- **通过股东代表大会行使**：涉及章程修改、重大战略决策等，需经上议院审议程序
- **直接行使**：两院僵局、紧急事态、章程授权范围内的事务

## 场景

### 下议院（公司代表大会）
- 代表选举：各业务域/职能域按席位分配规则选举代表
- 议案审议：代表提出议案，经审议后进入表决
- 表决机制：简单多数 / 三分之二多数
- 罢免程序：对不履职代表的罢免流程

### 上议院（股东代表大会）
- 立宪权：制定和修改章程的提案 → 审议 → 表决
- 司法权：裁决章程争议的受理 → 审理 → 裁决
- 创始人部分特权通过上议院行使
- 议事记录归档

### 创始人特权

#### 一票否决权
- **重大合规风险**触发：合规风险达到法定阈值
- **战略偏离**触发：公司战略方向偏离章程规定的核心使命
- **两院僵局**触发：上议院与下议院反复无法达成一致
- 行使路径：日常通过上议院行使；僵局时直接行使

#### 直接发布权
- 在章程授权范围内直接发出指令
- 适用于日常运营中章程已明确授权的事项

#### 其他特权
- 根据章程规定，保留其他未让渡的权力

#### 通用约束
- 所有特权的行使路径由章程明确（通过上议院 vs 直接行使）
- 行使流程：触发 → 判定 → 行使 → 记录
- 不得委托他人

## 验收标准

- [ ] 两院职权划分清晰，权力来源（创始人让渡）明确
- [ ] 下议院选举、审议、表决流程完整可执行
- [ ] 上议院立宪与司法流程完整
- [ ] 创始人特权范围清晰，一票否决权仅是子项之一
- [ ] 每项特权的行使路径明确（通过上议院 vs 直接行使）
- [ ] 不同行使路径的适用条件清晰可判定
- [ ] 存在不得委托他人的限制机制
- [ ] 所有特权行使形成书面记录
