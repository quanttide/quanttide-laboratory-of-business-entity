# p01: 议事机制

验证公司三级议事体系的可执行性：公司代表大会 → 议事会 → 创始人否决权。

## 场景

### 公司代表大会
- 代表选举：各业务域/职能域按席位分配规则选举代表
- 议案审议：代表提出议案，经审议后进入表决
- 表决机制：简单多数 / 三分之二多数 / 一票否决
- 罢免程序：对不履职代表的罢免流程

### 议事会（上议院）
- 立宪权：制定和修改章程的提案 → 审议 → 表决
- 司法权：裁决章程争议的受理 → 审理 → 裁决
- 议事记录归档

### 创始人一票否决权
- **重大合规风险**触发：合规风险达到法定阈值
- **战略偏离**触发：公司战略方向偏离章程规定的核心使命
- **两院僵局**触发：代表大会与议事会反复无法达成一致
- 行使流程：触发 → 判定 → 行使 → 记录
- 限制机制：不得委托他人

## 验收标准

- [ ] 公司代表大会的选举、审议、表决流程完整可执行
- [ ] 议事会的立宪与司法流程完整
- [ ] 创始人否决权的触发条件清晰可判定
- [ ] 三级议事体之间的衔接关系明确，无重叠或遗漏
- [ ] 每一层级行使后均形成书面记录
- [ ] 否决权存在不得委托他人的限制
