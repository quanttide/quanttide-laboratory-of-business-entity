# p01: 两院制议事机制

验证公司两院制议事体系的可执行性。

## 权力来源

创始人是大股东和实际控制人，两院的权力由创始人让渡。创始人在以下情形保留特权：

- **两院僵局**：上议院与下议院反复无法达成一致时，创始人可直接行使一票否决权或直接发布指令
- **直接发布**：在章程授权范围内，创始人可直接发布指令

## 场景

### 下议院（公司代表大会）
- 代表选举：各业务域/职能域按席位分配规则选举代表
- 议案审议：代表提出议案，经审议后进入表决
- 表决机制：简单多数 / 三分之二多数
- 罢免程序：对不履职代表的罢免流程

### 上议院（股东代表大会）
- 立宪权：制定和修改章程的提案 → 审议 → 表决
- 司法权：裁决章程争议的受理 → 审理 → 裁决
- 创始人一票否决权的行使场所（日常事务中由创始人直接行使）
- 议事记录归档

### 创始人特权
- **重大合规风险**触发：合规风险达到法定阈值
- **战略偏离**触发：公司战略方向偏离章程规定的核心使命
- **两院僵局**触发：上议院与下议院反复无法达成一致
- **直接发布**：在章程授权范围内直接发出指令
- 行使流程：触发 → 判定 → 行使 → 记录
- 限制机制：不得委托他人

## 验收标准

- [ ] 两院职权划分清晰，权力来源（创始人让渡）明确
- [ ] 下议院选举、审议、表决流程完整可执行
- [ ] 上议院立宪与司法流程完整
- [ ] 创始人特权触发条件清晰可判定（合规风险/战略偏离/两院僵局/直接发布）
- [ ] 两院僵局时创始人直接行使的路径明确
- [ ] 存在不得委托他人的限制机制
- [ ] 所有议事活动形成书面记录
