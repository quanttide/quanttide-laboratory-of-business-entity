职级双通道

依据《量潮科技职级管理章程》实现。专业序列（T）和管理序列（M）双通道发展体系。

整体晋升导向：鼓励向 管理序列（M） 发展，培养复合型管理人才，支撑多业务线融合与统筹需求。

专业序列（T）

L3
高级
主导复杂任务，方案设计与技术指导
L2
中级
独立承担完整项目模块，问题分析解决
L1
初级
独立完成常规任务，基本专业执行能力
L0
见习
实训生，在指导下参与基础工作

管理序列（M）

M5
董事
战略监督与重大决策
M4
总裁
公司整体战略方向与治理决策
M3
副总裁
跨部门战略协同与业务线管理
M2
总监
部门整体业务规划与资源统筹
M1
主管
业务团队管理与执行推进

晋升规则

序列内直升
T1 → T2 → T3
M1 → M2 → ... → M5

发展身份（前置阶段）

L0
实训生

—
实习生
带教培养，实习期满考核合格正式定级
—
培训生
系统培训 + 岗位实践，培训期满定级入职
—
管培生
跨部门轮岗，培养管理储备人才，合格后入M序列
