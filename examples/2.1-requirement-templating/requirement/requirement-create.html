业务目标
  • 熟练掌握对象存储的数据管理能力
  • 利用 ClickHouse 实现高效的列式查询与价格指数构建
  • 基于 Python 的自动化计算流程，实现高并发、可复用的价格指数计算和可视化
场景描述

基于 CPP 课题组十年积累的电商价格指数研究经验，采用 2026 年最新技术栈——对象存储替代本地文件、ClickHouse 替代 MongoDB、Python 自动化流水线替代手动运维——重新构建一套现代化高可用的高频价格指数计算方案。

目标用户为大数据课程学员，需在模拟电商数据集上完成从数据导入到可视化交付的完整端到端实践。
