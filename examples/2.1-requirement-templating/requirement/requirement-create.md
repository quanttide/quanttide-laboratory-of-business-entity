# 需求规格：大数据导论实践课

需求规格是原始需求的规范化录入，由业务目标、场景描述、样本数据路径和验收标准四个部分组成。需求创建后，下游经由蓝图拆解→伪代码编写→报价→变更管理形成完整的工程链路。

本需求规格是《量潮课堂大数据导论实践课任务书》的结构化提取，面向对象存储 + ClickHouse + Python 的现代技术栈，以高频价格指数计算为目标。

## 业务目标

构建一套自动化、高并发、可复用的高频价格指数计算和可视化体系。具体包括：
- 熟练掌握对象存储的数据管理能力
- 利用 ClickHouse 实现高效的列式查询与价格指数构建
- 基于 Python 的自动化计算流程，实现每日价格指数的计算和趋势可视化

## 场景描述

本项目源于 China's Prices Project（CPP）十年前积累的电商价格指数编制经验。原始方案依赖个人电脑爬虫和 MongoDB，面对每日 500 万数据点存在严重的性能和运维瓶颈。现采用 2026 年最新技术栈重新实现，以对象存储替代本地文件、ClickHouse 替代 MongoDB、Python 自动化流水线替代手动运维。

目标用户为大数据课程学员，需在给定的模拟数据集上完成从数据导入到可视化交付的完整端到端实践。

## 样本数据

教学团队提供三份模拟电商数据集，结构与量潮大数据示例仓库中的 data 目录一致：

| 文件 | 路径 | 内容 |
|------|------|------|
| category.csv | data/categories.csv | 商品三级分类，含权重 |
| product.csv | data/products.csv | 商品清单，归属叶子分类 |
| price.csv | data/daily_price/daily_prices_YYYYMMDD.csv | 按日分割的价格数据 |

## 验收标准

### 功能验收

- 数据导入：对象存储中 Bucket 创建成功，ClickHouse 中三张表（category/item/price）创建并导入数据
- 数据清洗：空值和异常价格被过滤，字段类型统一为约定格式
- 指数计算：产出 cavallo_index.csv 和 tmall_index.csv，包含日期、指数值和基期日期
- 可视化：生成日度指数趋势图（PNG 或 HTML）

### 质量验收

- 商品覆盖率达到 80% 以上
- 异常过滤准确率达到 95%（可选）

- 实践报告：需求分析、表结构设计、SQL 算法与关键语句分析、代码详情、运行截图、心得
- 源程序：完整可运行的 Python 项目代码
