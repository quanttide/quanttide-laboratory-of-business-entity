# p17: 周会审计全流程

验证会前、会中、会后的完整审计流程。

## 场景

- 会前审计：议题提报 → 审计 → 通过/退回
- 会中审计：议题质量 / 议程执行 / 议事规则评分
- 会后审计：审计报告与周报审核时限

## 验收标准

- [ ] 议题提报有固定模板和截止时间
- [ ] 会前审计有明确的合格标准
- [ ] 不通过的议题被退回并告知原因
- [ ] 退回议题可在补充后重新提报
- [ ] 议题质量评分标准（完整性、数据支撑、方案建议）
- [ ] 议程执行评分标准（时间控制、议题顺序、完成度）
- [ ] 议事规则评分标准（发言秩序、辩论聚焦、主持人中立）
- [ ] 评分结果实时记录并在会后反馈
- [ ] 审计报告于周四前完成审核
- [ ] 周报于周五前完成审核
- [ ] 审计报告包含：会议摘要、议题评分、改进建议
- [ ] 周报经由审计负责人确认后发布
