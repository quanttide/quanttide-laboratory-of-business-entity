# p12: 沟通摘要规则与违规认定

验证 500 字摘要规则的实际应用及违规认定处理。

## 场景

- 原文 vs 摘要对照：展示信息精炼前后的对比
- 违反摘要规则的认定与处理

## 验收标准

- [ ] 原文超过 500 字时被有效精炼
- [ ] 摘要保留核心信息和关键结论
- [ ] 摘要末尾可附「如需查看全文请访问...」
- [ ] 摘要规则在团队渠道中得到执行
- [ ] 违规认定标准清晰（超过 500 字未做摘要 / 发送 AI 对话原文 / 未处理原始信息）
- [ ] 认定后有正式告知和记录
- [ ] 处理措施明确（警告 / 记录 / 升级）
- [ ] 多次违规有累进处理机制
