**第十六条 规范用语**
制度性内容应使用以下规范用语：

| 含义 | 用语 |
|------|------|
| 强制义务 | "应当""须""必须" |
| 禁止行为 | "不得""禁止" |
| 授权允许 | "可以""有权" |
| 推荐非强制 | "宜""建议" |

同一含义在全仓库范围内应使用同一用语，避免混用。
