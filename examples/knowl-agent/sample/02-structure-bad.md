# AGENTS.md — 审计章程维护原则

## 文档定位

审计章程是公司审计制度的规范性文件，非操作手册。所有内容应保持**通用、稳定、长期有效**。

## 维护原则

### 1. 章程要通用

- 不记录具体人名、团队名称、阶段性推进状态
- 不记录尚未确定的计划或意向
- 去掉"当前阶段""下一步"等时效性表述

### 2. 按域分文件

- 一个业务域一个 `audit.md`，放在对应目录下
- 通用规则归 `audit/index.md`（总纲）
- 不混合不同域的内容在同一文件

### 3. 总纲管全局

- `audit/index.md` 放所有域共享的通用规则
- 各域 `audit.md` 只放本域特有的审计要点

### 4. 元审计单独存放

- `audit/audit.md` 作为元审计章程，不与其他域合并

### 5. 命名规范

- 文件名统一 `snake_case`
- 审计章程文件统一命名为 `audit.md`
- 总纲使用 `index.md`

### 6. 标题层级

- 文档主标题使用 `#`（一级标题）
- 章节使用 `**第X条**` 格式，非标题语法

## 目录结构

```
audit/
├── index.md     # 审计总纲（通用规则）
├── audit.md     # 元审计章程
project/
├── audit.md     # 项目质量审计章程
qtclass/
├── audit.md     # 业务审计章程
```

## 清理规范

- 操作手册、运营指南等非审计内容，不进审计目录
- 过时文件直接删除，不保留空壳
- AI 生成残留（对话痕迹、确认用语）提交前必须清除
