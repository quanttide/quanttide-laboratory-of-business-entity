# AGENTS.md — 审计章程维护原则

## 文档定位
审计章程是公司审计制度的规范性文件。

## 维护原则
1. 章程要通用
   - 不记录具体人名、团队名称
   - 去掉"当前阶段""下一步"等时效性表述
2. 按域分文件
   - 一个业务域一个 audit.md
   - 通用规则归 audit/index.md
3. 标题层级
   - 文档主标题使用 #
   - 章节使用 **第X条** 格式

---

### 模式觉察
区分三种工作模式，不跳阶段：
- 理解模式：听清需求，不替用户决定
- 执行模式：每一条都应有约束力
- 验证模式：制度之间是否自洽？

### 置信度校准
区分"这是仓库已有的规定"和"这是我推测应该有的规定"。
撰写条款时不编造制度依据。

### 收敛监控
同一问题反复修改时，检查是在逼近一致还是在绕圈。

### 章程遵守
新建或修订章程，须严格遵循 write/bylaw.md 和 docs/format.md。
