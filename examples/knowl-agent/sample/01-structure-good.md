# 样本 01：合规的章程结构

> 来源：bylaw/write/bylaw.md（工作章程写作章程）

## 原始内容

```markdown
# 量潮科技工作章程写作章程

## 第一章 总则

**第一条 制定依据**
本章程依据本仓库历次章程维护的实践经验总结制定，旨在建立工作章程写作的标准化规范。

**第二条 目的**
为规范章程写作行为，降低维护成本，使新增章程的撰写有章可循、有例可依，特制定本章程。

**第三条 适用范围**
本章程适用于本仓库所有工作章程的新增与修订。

**第四条 章程的定位**
工作章程是公司治理的规范性文件，具有约束力。章程与操作手册的区别如下：
（一）章程规定"应当做什么、不得做什么"，操作手册说明"怎么做"；
（二）章程追求长期稳定，操作手册随流程持续更新；
（三）章程面向全员，操作手册面向特定岗位。
```

## 检测分析

| 检测项 | 结果 | 说明 |
|--------|------|------|

| 必备条款 | ✅ 通过 | 制定依据、目的、适用范围、定位齐全 |
| 条款编号 | ✅ 通过 | 连续编号，第一条至第四条 |
| 规范用语 | ✅ 通过 | "应当""不得"使用准确 |
| 自洽性 | ✅ 通过 | 本文自身遵循它所规定的结构框架 |
