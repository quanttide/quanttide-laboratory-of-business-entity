# p07: 商务报价全流程

验证商务报价从定价策略到审批完成的完整流程。

## 场景

- **定价策略**：稀缺性定价、机会成本参照、创新溢价、长期关系定价
- **基准价格表**：客户分类（企业/高校/学生/其他）× 人员分级（首席/资深/高级/中级/初级）
- **审批流程**：标准报价（直接审批）/ 重大报价（升级审批）/ 让利报价（特殊审批）

## 验收标准

- [ ] 每种定价原则至少有一份报价单样例
- [ ] 定价说明中标注所采用的定价原则和依据
- [ ] 价格表覆盖所有客户分类 × 人员分级组合
- [ ] 学生客户享有差异化优惠
- [ ] 高复杂度项目可启动溢价报价的标注
- [ ] 价格有效期和调整机制明确
- [ ] 三类审批的判定标准清晰
- [ ] 每类有对应的审批路径和审批人
- [ ] 审批流转有书面记录
- [ ] 审批不通过有退回和修订机制
