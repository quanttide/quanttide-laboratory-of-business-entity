# p14: 客户分级全流程

验证客户对外等级权益、对内分类资源配置及升降级流程。

## 场景

- 对外等级：普通客户 / VIP 客户 / SVIP 客户的权益差异
- 对内分类：SMB（中小企业）/ LA（大型客户）/ KA（关键客户）
- 升降级：消费金额与频次、合作时长、推荐贡献等触发条件

## 验收标准

- [ ] 三级权益差异表清晰完整
- [ ] SVIP 权益包含：更高折扣、优先体验新产品、品牌曝光、专属客户经理
- [ ] 各等级的门槛条件明确
- [ ] 权益条款可执行、可交付
- [ ] 每类客户的资源投入标准明确
- [ ] KA 享有：专属客户经理、技术支持团队、定制化方案、高层定期拜访、参与产品规划
- [ ] 分类调整有触发条件和审批流程
- [ ] 升级和降级的触发条件量化可判定
- [ ] 升级/降级有正式审批和通知流程
- [ ] 客户等级变更后权益同步调整
- [ ] 降级或退出有客户沟通和过渡方案
