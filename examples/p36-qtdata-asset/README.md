# p36: 数字资产管理

验证数字资产全流程管理：分类归档 → 版本标注 → 内部审核 → 客户确认。

## 场景

- 资产分类：数据工程（数据集、文档、处理器）、项目管理（策划书、需求规格、进度报告、变更记录、验收报告、复盘报告）、商务管理（报价单、合同、发票、客户沟通）
- 版本管理：数据集标注版本号、文档标注版本号和修改日期、代码语义化版本
- 交付流程：打包 → 内部审核 → 客户确认（超期未反馈视为通过）

## 验收标准

- [ ] 项目经理在 7 个工作日内完成全部资产归档
- [ ] 资产版本号标注规范
- [ ] 内部审核流程执行到位
- [ ] 客户确认机制（含默认通过规则）
- [ ] 超期原始数据按合同约定清理
