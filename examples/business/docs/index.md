# 商务拓展域实验 — 评估产出

Assets → Data → Code → Docs 管线的最终输出。

## 模糊点（asset.md）

从章程、手册、教程中找出 7 处模糊点，集中在三方面：定价参数未定义（"金额标准""让利比例""保本线"均缺具体数值）、人员定价缺失（资深/中级/初级标注为"待补充"）、定性评估无量化标准（稀缺性/创新溢价/长期价值全凭主观判断）。这些模糊点在纯文本阅读时不易察觉，但一旦试图编码就不可回避。

## 可编码性评分（clarity-scores.md）

对 15 条报价规则按 1-5 分打分。8 条得 5 分（直接可编码），集中在 profile 中的确定数值和 handbook 中的枚举条件。5 条得 2 分（模糊需补充），2 条得 1 分（无法编码）。整体可编码率 53%——约一半规则清晰到可直接翻译为代码，另一半需要文档改进。

## 编码发现（findings.md）

编码过程中暴露 5 个具体问题：保本线未定义、资深/中级/初级定价缺失、金额标准与让利比例未制定、高校客户依赖个案谈判、三大评估要素无量化标准。每个问题都标注了出处和改进建议。同时发现手册的 10 条"不得"规则非常适合编码为断言校验。

## 实验报告（experiment-report.md）

管线全流程跑通验证。核心结论：可编码性评分可作为文档质量的客观度量；知识蒸馏管线（Assets→Data→Code→Docs）可行，每步都暴露了上游问题；53% 的可编码率说明文档体系有约一半已清晰达标，另一半有明确改进方向。
