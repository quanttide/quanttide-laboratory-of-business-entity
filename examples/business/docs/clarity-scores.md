# 可编码性评分

评分标准：
- 5 = 直接可编码
- 4 = 微调后可编码
- 3 = 需补充信息
- 2 = 模糊，需重写
- 1 = 无法编码

| 规则 | 来源 | 分数 | 理由 |
|------|------|------|------|
| 首席企业客户定价 | profile | 5 | 2,000 元/小时，确定数值 |
| 高级企业客户定价 | profile | 5 | 1,000 元/小时，确定数值 |
| 溢价条件判断 | handbook | 5 | 枚举条件，无歧义 |
| 溢价幅度范围 | profile | 5 | 30-50%，确定范围 |
| 让利规则（满10h 9折） | profile | 5 | 确定性规则 |
| 让利规则（满20h 8.5折） | profile | 5 | 确定性规则 |
| 审批层级判断 | handbook | 5 | 三类条件逻辑清晰 |
| 报价单结构比例 | handbook | 5 | 固定比例 3:4:3 |
| 首次合作保本线 | profile | 2 | "保本线"未定义数值 |
| 稀缺性评估 | bylaw | 2 | 四个维度均需主观判断 |
| 创新溢价评估 | bylaw | 2 | 定性评估，无量化标准 |
| 长期合作价值评估 | bylaw | 2 | 定性判断 |
| 资深/中级/初级定价 | profile | 1 | 人员与价格均为"待补充" |
| 高校客户定价 | profile | 2 | "按合作协议"，非确定值 |
| 其他客户定价 | profile | 1 | "一事一议"，无规则 |

## 统计

- 5 分（直接可编码）：8 条
- 2 分（模糊需补充）：5 条
- 1 分（无法编码）：2 条
- 可编码率（≥4 分）：8/15 = 53%
