# 商务拓展职能成熟度实验

## 意图

检验章程、手册、教程提取的知识结构是否可以变成清晰的代码。

## 核心洞察

**章程→手册→教程 构成了知识蒸馏管线，代码是最终的结晶验证。**

- `docs/bylaw`（宪法层）定义最高约束原则
- `docs/handbook`（法律层）定义可操作流程
- `docs/tutorial`（教学层）定义学习路径
- `examples/default`（实验室）将三级知识结构映射为代码

商务拓展被选为第一个实验域，因为其流程边界清晰（从线索到签约有完整生命周期），适合验证这条管线的可行性。若成功，意味着治理体系的知识可以「编译」成可执行的软件系统——**治理即代码**。

## 洞察

如果文本可以清晰地描述规则，则可以直接变成代码。如果不可以，则说明文本有改进空间，则找到了改进的方向。
